# ミッシングファンダメンタル体験アプリ

純音を重ねて、基音（f0）がなくても f0 の高さが聞こえることを体験する、スマホ用の静的Webアプリです（`index.html` 1枚のみ、外部ライブラリなし）。

## 公開URL
https://uec-aiba.github.io/missing-fundamental

## 機能
- 純音ボタン12個（4×3）から周波数を選び（もう一度押すと解除）、再生ボタンで、選んだ音を同時に2秒間鳴らす
- 周波数の刻みを 100／200／300／400 Hz から選べる（初期値 300 Hz）。刻みを切り替えると、選択は解除される
- 上部に、スペクトル（模式図）と合成波形（30 ms）を表示
- 選んだ音の共通の基本周波数 f0 を計算し、f0 が含まれていない場合は「ミッシングファンダメンタル」と表示（スペクトル上に破線で f0 を表示）。9次以上の高次倍音だけの場合は、ピッチが聞こえにくいことも表示
- 音量スライダー、「選択を解除」ボタン、画面下に「オーディオの状態」を表示

## 授業用のURL設定
なし（刻みと音の選択は、画面上で行う）。

## 使用上の注意
- イヤホン（ヘッドホン）を推奨。スマホ内蔵スピーカーは 300〜500 Hz 未満が弱く、100・200 Hz 刻みでは f0 の成分が出ない。機種差があるので、授業前に確認する
- 400 Hz 刻みは最高音が 4.8 kHz になり、位相固定の限界（約 4〜5 kHz）に近い
- 音は、最初のボタン操作のあとに鳴る（ブラウザの自動再生制限のため）
- iPhone はマナーモードを解除し、Safari で開く（Claudeアプリ内のプレビューでは鳴らないことがある）
- 画面を離れると、音は自動で止まる
iPhone はマナーモードを解除し、Safari で開く（Claudeアプリ内のプレビューでは鳴らないことがあります）
- 画面を離れる（バックグラウンドにする）と、音は自動で止まります
