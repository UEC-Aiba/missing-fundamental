# ミッシングファンダメンタル体験アプリ

スマホのブラウザで動く、ミッシングファンダメンタル体験用の静的Webアプリです（`index.html` 1枚のみ、外部ライブラリなし）。

公開URL：https://uec-aiba.github.io/missing-fundamental

## 機能
- 純音ボタン12個（4×3）。ボタンで周波数を**選び**（もう一度押すと解除）、下の再生ボタンで、選んだ音を**同時に**2秒間鳴らす（同時に鳴らすと、1つの音として聞こえやすい）
- 周波数の刻みを100／200／300／400 Hz から選べる（初期値300 Hz）。刻みを切り替えると、選択は解除される
- 上部にスペクトル（模式図）と合成波形（30 ms）を表示
- 選んだ音の共通の基本周波数 f0 を計算し、f0 の成分が含まれていない場合は「ミッシングファンダメンタル」と表示（スペクトル上に破線で f0 を表示）。9次以上の高次倍音だけの場合は、ピッチが聞こえにくいことも表示
- 音量スライダー、「選択を解除」ボタン、画面下に「オーディオの状態」の表示

## GitHub Pages で公開する手順
1. GitHub で新しいリポジトリを作成する（例：`missing-fundamental`、Public）
2. `index.html` をリポジトリのルートにアップロードする
3. Settings → Pages → Source を「Deploy from a branch」、Branch を `main` / `(root)` にして Save
4. 数分後、`https://<ユーザー名>.github.io/<リポジトリ名>/` で開ける。このURLをQRコードにして配布すると便利
5. 更新するときは、同名の `index.html` を上書きアップロードする（反映まで数分）

## 注意
- 音は最初のボタン操作の後に鳴ります（ブラウザの自動再生制限のため）
- イヤホン推奨。スマホ内蔵スピーカーは300〜500 Hz未満が弱く、100・200 Hz刻みでは、f0 の成分がスピーカーから出ません（機種差があるので、授業前に手元のスマホで確認してください）
- 400 Hz刻みは最高音が4.8 kHzになり、位相固定の限界（約4〜5 kHz）に近い
- iPhone はマナーモードを解除し、Safari で開く（Claudeアプリ内のプレビューでは鳴らないことがあります）
- 画面を離れる（バックグラウンドにする）と、音は自動で止まります
